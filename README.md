# Riskbaserad-Tidplanering-och-Optimering
Utveckling av en riskbaserad tidplansmodell för ett storskaligt infrastrukturprojekt. Från rekonstruktion av tidplan och aktivitetsberoenden utifrån projektdata till modellering av osäkerheter, Monte Carlo-simulering och kritikalitetsanalys. Resultaten används för att utveckla kostnadseffektiva åtgärdsstrategier och förbättra projektstyrningen.
